# Generated models

This directory holds trained XGBoost files created by `python -m ml.train`.

Safe to commit:
- `README.md`
- `.gitkeep`

Do not commit:
- `xgb_national_intensity.json` and other large generated model files
- `feature_columns.json` produced by a local training run (regenerated by the trainer)

Training metrics that are safe to commit live in `ml/artifacts/training_metadata.json`.
